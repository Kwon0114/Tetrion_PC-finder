Tetrion PC Finder

보드

퍼클 탐색은 아래쪽 8줄까지만 지원합니다. 9줄 이상 쌓인 보드는 8줄 안에서 끝나는 해만 찾아요.

피스

[ ] 묶음 · 안은 띄어 써도 됨 · 중첩 가능
자동입력: [ 입력 시 ] 추가 · SZ] → [SZ] · []!SZ>LJ} → []!{SZ>LJ}
숫자 = 뽑을 개수(생략 시 1개, 쓴 순서 유지)
! = 섞기(개수 생략 시 전부)

[TIL] T·I·L 중 1개
[TIL]2 TI·TL·IL 중 하나
[TIL]! 3개 전부 섞어서
[TIL]2! 2개를 섞어서

[]! = [IOTSZJL]! → 기본으로 7-bag 지정
% = bag 여부 뒤집기 (일반 묶음에 붙이면 bag 지정, []에 붙이면 해제)
※ 세이브는 bag으로 지정된 묶음 기준으로 계산돼요 (해제하면 계산 안 함)

예: [TIL]!JSZ
예: [[SZ]! [LJ]!]2!

{A<B} = 묶음 뒤에 붙이는 순서 조건 (A의 피스가 모두 B보다 앞, 나머지는 자유)
{B>A} 도 같은 뜻 (B가 A보다 뒤)
예: []!{LJ<SZ} = []!{SZ>LJ}
